# Loan Simulator

A simple interactive loan simulator developed using **Python** and **Streamlit**. The application allows users to enter loan information and calculate the estimated monthly payment and total repayment.

## 🚀 Live Demo

[Open the Loan Simulator](PASTE_YOUR_STREAMLIT_LINK_HERE)

## 📌 Features

* Enter loan amount
* Enter interest rate
* Select loan tenure
* Calculate estimated monthly payment
* Calculate total repayment
* Interactive Streamlit interface

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* NumPy

## ⚙️ How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

2. Open the project folder:

```bash
cd loan-simulator
```

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run the Streamlit application:

```bash
streamlit run app.py
```

5. Open the local URL shown in the terminal.
